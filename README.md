# React Country Selector with Autocomplete

## Overview
This is a React component for a country selector with autocomplete functionality. Users can type to search for a country, navigate through the list using the up and down arrow keys, and select a country by pressing Enter or clicking on the result.

## Features

- Autocomplete search with highlighting
- Navigation through the list using arrow keys
- Selection of a country on Enter key press
- Smooth scrolling of the list when navigating

## Installation

1. Clone the repository:
```sh
git clone https://github.com/laurapastor/country-selector.git
```
2. Install dependencies:
```bash
npm install
```
3. Start the development server:
```bash
npm start
```
